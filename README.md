# Welcome 👋

A welcome site for yerry262 and Claude — a static landing page rendered via GitHub Pages.

## 🌐 Live Demo

**[https://yerry262.github.io/Welcome/](https://yerry262.github.io/Welcome/)**

## 🛠️ Tech Stack

- **Frontend**: Static HTML/CSS/JS
- **Build Tool**: Vite 5.4
- **Deployment**: GitHub Pages (via `gh-pages`)

## 🚀 Getting Started

```bash
git clone https://github.com/yerry262/Welcome.git
cd Welcome
npm install
npm run dev      # local development
npm run deploy   # deploy to GitHub Pages
```
